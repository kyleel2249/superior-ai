# SUPERIOR AI

**One AI. An Entire Team Behind It.**

Production-oriented multi-model autonomous AI operating system — not a thin chatbot wrapper.

## Quick start (all platforms)

```bash
cp .env.example .env   # Windows: copy .env.example .env
npm install
npm run dev:web
```

Open http://localhost:3000

```bash
npm run smoke
```

## Windows (npm)

```bat
copy .env.example .env
npm install
npm run dev:web
```

Full guide: [docs/runbook/WINDOWS.md](docs/runbook/WINDOWS.md)

Requires **Node.js 20+**. PostgreSQL and Redis are optional for basic local use.

## Key routes

/chat · /workspace · /studio · /status · /admin/packs · /publisher

## Design rules

No invented metrics, contacts, or test results. Official APIs only for social/CRM. Native vs upscaled image labels. Future models register without core redesign.
